# Модульное приложение «Алгоритмическая обработка числовых рядов» (Вариант 2)

Консольное приложение на Python для генерации числовых рядов, вычисления базовых и дополнительных статистических показателей, сглаживания методами скользящей средней (через `list` и отдельный модуль на `collections.deque`), а также сохранения и загрузки данных в форматах JSON, CSV и TXT.

---

## Особенности Варианта 2

* **Генерация ряда:** 500 чисел из нормального распределения с параметрами \(\mu = 50, \sigma = 10\) (`random.gauss`). По умолчанию в CLI используются `n = 1000`, `window = 10`.
* **Статистические показатели:**
  * Базовые: среднее арифметическое (`mean`), медиана (`median`), размах (`spread`), СКО (`stdev`).
  * Дополнительный показатель: **мода (`mode`)** на базе `collections.Counter` (при наличии нескольких мод возвращается отсортированный список).
* **Скользящие средние:**
  * Простая скользящая средняя (`SMA`) — две реализации: через бегущую сумму по списку (`moving_average.py`) и через двустороннюю очередь (`deque_average.py`) со сложностью \(O(n)\).
  * Взвешенная скользящая средняя (`WMA`) с линейными весами \(1, 2, \dots, k\).
* **Краевой кейс:** ряд из одинаковых значений (`constant`), для которого \(\text{СКО} = 0\), а мода и скользящие средние совпадают с константой.

## Архитектура и контракт данных

Все модули изолированы и обмениваются данными через стандартные последовательности Python (`Sequence[float] -> list[float]`):
1. `generator.py` / `io_json.py` / `io_file.py` — формируют или загружают исходный ряд `list[float]`.
2. `stats.py` — вычисляет статистические метрики.
3. `moving_average.py` и `deque_average.py` — выполняют сглаживание и сравнение производительности.
4. `main.py` — оркестрирует работу модулей через аргументы командной строки (`argparse`).

## Примеры запуска

### 1. Генерация и анализ по Варианту 2
Запуск генерации 500 чисел нормального распределения ($\mu=50, \sigma=10$) с окном $k=10$:
```bash
python main.py --kind gauss --n 500 --window 10 --seed 42
```

### 2. Проверка краевого кейса (одинаковые значения)
Генерация ряда из одинаковых чисел для проверки, что СКО равно 0:
```bash
python main.py --kind constant --n 500 --window 10
```

### 3. Сохранение и загрузка файлов (JSON / CSV / TXT)
Генерация ряда и сохранение в JSON с метаданными:
```bash
python main.py --kind gauss --n 500 --save data/gauss.json
```

Загрузка сохранённого ряда из JSON или CSV и его анализ:
```bash
python main.py --load data/gauss.json --window 10
python main.py --load data/series.csv --window 5
```

Экспорт сгенерированного ряда в CSV:
```bash
python main.py --kind gauss --n 500 --export out.csv
```

## Замер производительности скользящей средней

Для сравнения скорости работы реализаций SMA через список (`list`) и двустороннюю очередь (`deque`) за 1000 прогонов используйте флаг `--benchmark`:
```bash
python main.py --kind gauss --n 5000 --window 20 --benchmark
```
Программа выведет среднее время выполнения (в секундах) для обеих реализаций и их отношение (`list / deque`).
